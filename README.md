# 143 Overwatch Finlad Server Excluder

Компактная Windows-утилита для переключения двух режимов через штатный Windows Firewall.

- **SOLO** — включает блокировку заданных диапазонов GEN1.
- **PARTY** — отключает правила приложения. Режим первого запуска.

Тёмный интерфейс 143 Aim Club, системный трей, сохранение режима, автозапуск, восстановление правил и настройки уведомлений. C# / WPF / .NET 10, Windows 10/11 x64. Название **Finlad** сохранено намеренно.

## Скачать и запустить

1. Откройте **Releases** и скачайте `143-Overwatch-Finlad-Server-Excluder-win-x64.zip`.
2. Распакуйте в постоянную папку и запустите `143 Overwatch Finlad Server Excluder.exe`.
3. Подтвердите запрос администратора. Выберите **SOLO** или **PARTY**.

.NET устанавливать отдельно не нужно: runtime включён в единственный exe. Сборка не имеет платной цифровой подписи, поэтому Windows может показать предупреждение о неизвестном издателе. SHA256 приложен к релизу.

Крестик и кнопка сворачивания скрывают окно в трей. ЛКМ по значку открывает окно; ПКМ позволяет сменить режим, включить автозапуск или выбрать **Exit**. Выход **не отключает** выбранные firewall-правила: сначала выберите PARTY, если хотите снять блокировку.

## Какие правила изменяются

| Правило | Удалённые адреса |
|---|---|
| `143 OW Server Switch — GEN1 34.88` | `34.88.0.0-34.88.255.255` |
| `143 OW Server Switch — GEN1 35.228` | `35.228.0.0-35.228.255.255` |

Исходящие соединения, действие Block, все профили и протоколы. Группа владельца: `143OWServerSwitch.Managed.v1`.

**Блокировка распространяется на все приложения компьютера**, а не только Overwatch. Диапазоны взяты из задания; приложение не проверяет расположение серверов и не гарантирует выбор региона матчмейкинга. PARTY отключает только собственные правила и не отменяет ограничения других программ или сетевых политик.

При запуске сохранённый режим восстанавливается: отсутствующие правила создаются, дубликаты и повреждённые параметры исправляются. Старые правила с точными именами и пустой группой принимаются под управление. Совпадение имени с чужой непустой группой вызывает ошибку без изменения правил.

Статус переключается после записи и проверки обоих правил. При ошибке выполняется попытка отката к предыдущему состоянию. Если не удалось сохранить config, правила тоже откатываются. Раз в 10 секунд состояние проверяется: ручное изменение правил показывает **CHECK RULES**, выключенный firewall или ограничивающая политика — **NOT ACTIVE** для SOLO. Нажатие SOLO/PARTY повторно восстанавливает правила. Приложение не включает сам Windows Firewall и не изменяет групповые политики.

## Права и автозапуск

Приложение начинает работу с обычными правами и перезапускает себя через стандартный UAC с правами администратора. Один запрос при запуске, без новых запросов на каждое переключение. Отмена UAC показывает ошибку и кнопку **Restart as administrator**.

`Run on startup` использует `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `143OWServerSwitch`. Планировщик заданий и службы не используются. **При входе в Windows требуется подтвердить UAC**; без этого изменения правил недоступны. `Start minimized` скрывает главное окно, но не может скрыть UAC.

Рассчитано на администратора с UAC в той же учётной записи. Если стандартный пользователь вводит данные другой учётной записи администратора, настройки и HKCU будут принадлежать этой другой учётной записи. Для такого сценария в v1 не предусмотрена отдельная служба/helper.

После переноса exe запустите его из новой папки: существующая запись автозапуска обновится. Повторный запуск активирует уже открытый экземпляр после elevation.

## Настройки и удаление

`%LocalAppData%\143OWServerSwitch\config.json` хранит режим, уведомления, автозапуск, сворачивание и позицию окна. Запись выполняется через временный файл и атомарную замену. Невалидный config не перезаписывается молча: приложение предлагает исправить его и повторить запуск.

Логи: `%LocalAppData%\143OWServerSwitch\logs\`. Ротация ограничена двумя файлами примерно по 512 KiB. Телеметрии и сетевых запросов нет.

**Settings → Remove firewall rules** удаляет только два правила приложения с его маркером владельца, отключает автозапуск, сохраняет PARTY и завершает процесс. Затем можно удалить exe. При новом запуске правила будут созданы снова.

## Сборка

На Windows с [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0):

```powershell
./build.ps1
```

Результат: `artifacts/143 Overwatch Finlad Server Excluder.exe`. Внешних NuGet-пакетов нет. GitHub Actions выполняет тесты ядра и сборку на Windows.

```powershell
dotnet run --project tests/Excluder.Tests -c Release
```

Для проверки интерфейса без UAC, изменения firewall и автозапуска:

```powershell
& '.\artifacts\143 Overwatch Finlad Server Excluder.exe' --preview
```

Preview использует отдельную конфигурацию в `%TEMP%\143OWServerSwitch.Preview`; в интерфейсе постоянно отображается `PREVIEW · no system changes`.

## Проверки

Автотесты покрывают создание, переключение, восстановление, дедупликацию, нормализацию адресов, откат при сбое firewall и config, защиту чужих правил, удаление, сохранение настроек и обнаружение ручных изменений. Они работают на тестовом хранилище и не меняют настройки компьютера.

См. [CHECKLIST.md](CHECKLIST.md) для проверок на реальной Windows. Успешная сборка и автотесты не заменяют проверку UAC, перезагрузки, разных DPI и реального матчмейкинга.

Никаких DLL injection, драйверов, чтения памяти, изменения игровых файлов, Battle.net API, VPN или overlay.

Техническая основа: [Windows Firewall COM API](https://learn.microsoft.com/en-us/windows/win32/api/netfw/nn-netfw-inetfwpolicy2).
